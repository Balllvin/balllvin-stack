# Harvest event pages

Copy an event's about text and helpful resources into a knowledge notebook. Calendar, RSVP, and conflicts stay in an ops notebook. What was taught goes in a subject notebook (a Cursor workshop goes under Cursor material, a design talk under design).

## When

After someone attends or points at an event, or when you need to teach from past events. Do not re-register. Do not click Request to Join or submit any event form from this skill.

## Steps

1. Confirm you can write to the notebooks. If the tool fails, record the command, the error, and what you wanted, and fix access before inventing a workaround.
2. Open the event page (for a Luma event, open it so the drawer or modal appears). Scroll the about text and copy it.
3. Open every helpful-resources link in a new tab.
4. On each docs page, use the site's own copy-page control when it has one, so you get the demonstrated copy, not a paraphrase. A markdown accept header on the docs URL is a fine equivalent.
5. Write the copied markdown into the subject notebook. Keep a short index of events in the same notebook. Ops, RSVP, and conflicts stay in the ops notebook.
6. If the notebook tool errors, record the command, the error, and the intent, then fix it.

## Inputs vs constants

- **Input:** which event (URL or title)
- **Constant:** one ops notebook for calendar and RSVP, one subject notebook for taught material. Never submit event forms from this skill.
